Домашние дела —
в одном Telegram-приложении

Reminder Bot, или «Мой дом», помогает вести личные и общие дела. Mini App показывает задачи, календарь и прогресс, а бот напоминает о запланированном в Telegram.

Задачи, расписание и прогресс

Задача проекта

Разовые напоминания не показывают общую картину домашних дел: что запланировано, что повторяется и что уже сделано. В личном проекте я объединил расписание, напоминания и общий список задач с удобным интерфейсом внутри Telegram.

  1. ЗадачаСоздать дело и указать, личное оно или общее.
  2. РасписаниеЗадать дату, время или повторение.
  3. НапоминаниеПолучить сообщение в Telegram в соответствии с расписанием.
  4. ВыполнениеОтметить дело выполненным и посмотреть прогресс в профиле.

Что умеет приложение

Личные и общие дела

Задачи можно вести для себя или вместе с командой. Реализованы создание команды, вступление и управление участниками.

Повторяющиеся напоминания

Поддерживаются разовые даты и повторения по расписанию, в том числе несколько напоминаний в день. Учитывается часовой пояс пользователя.

Сегодня и календарь

Список на день и календарь помогают переходить от ближайших дел к планам на другие даты. Выполнение отмечается прямо в приложении.

Профиль и оформление

Профиль показывает статистику выполнения и серии дней с выполненными делами. Есть светлая, тёмная и автоматическая темы.

Интерфейс в четырёх экранах

Иллюстрации интерфейса с демонстрационными данными. Нажмите на экран, чтобы открыть его в полном размере.

Как устроено решение

Backend написан на Java 21. Встроенный HttpServer отдаёт Mini App и API, PostgreSQL хранит задачи и расписания, Liquibase управляет схемой базы. API проверяет подписанные данные Telegram. Планировщик обрабатывает расписания, а статистика считается с учётом часового пояса пользователя.

  • Java 21
  • PostgreSQL
  • Liquibase
  • Java HttpServer
  • HTML / CSS / JavaScript
  • Maven

Результат разработки

В одном проекте связаны создание задачи, настройка расписания, уведомления в Telegram и отметка о выполнении. Mini App дополняет переписку с ботом календарём, общими делами и наглядным профилем.

Контекст и границы версии

Это личный проект, а не внедрение для заказчика. Скриншоты показывают интерфейс с примерными задачами и статистикой. Текущая архитектура рассчитана на один экземпляр бота; отдельная надёжная очередь повторной доставки уведомлений не реализована.
